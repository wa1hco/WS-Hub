DX cluster Spots from a DX cluster, read only. WS Hub does not post spots. A click on Operate selects the station. It does not transmit and it does not retune a radio. Work still needs a live decode. Spots drop off after 15 minutes.

Skim receivers WS Skim decodes the whole band and sends what it hears the same way WSJT-X does. WS Hub shows those stations on the Operate Spotted list with a green SKIM tag, first in the list, because they were heard here. A skimmer is receive only. It is never listed as a WSJT-X program, and nothing in WS Hub can reply to it or set it up. A click on a SKIM spot selects the station, the same as a cluster spot. It does not transmit, retune, or turn an antenna. Skim spots work with the DX cluster off.

Where to point WS Skim In WS Skim, open Reporting, check WSJT-X UDP Enable, and set Port to 2237. For Host, use 224.0.0.73, which reaches the site server from any PC on this network. 127.0.0.1 works only when WS Skim runs on the same PC as the site server. This site server's own address also works as Host.

Networking checklist

Flat LAN; WSJT-X multicast by band port; N1MM external broadcast to WS Hub; see docs/plan/wims_networking.md.

  • WSJT-X UDP Server = fleet multicast (e.g. 224.0.0.73), not 127.0.0.1
  • WSJT-X Outgoing interface = contest LAN NIC (never blank / @Invalid() / loopback)
  • N1MM Broadcast Data → Contacts + Radio → 127.0.0.1:12060 + N1MM agent
  • N1MM WSJT/JTDX UDP reader OFF (digi → N1MM is agent Log; avoid double-log)
  • Host firewall allows console TCP 8787 from operator PCs / VMs
  • Site server presence UDP 8788 (multicast) — second server refuses; agents show clickable console links
  • Unique WSJT-X --rig-name / UDP id per instance
  • One site server only — seats run agent + N1MM/WSJT-X, not a second wims.server

IF-reporting seats

Most radios report RF (Flex / SmartSDR XVTR, Icom with the transverter offset on). WS Hub labels that dial as heard: 28.074 MHz stays 10m. Check a seat only when its radio reports the IF — Roy 222 is a 21 MHz radio (→ 222) and Roy 432 is a 28 MHz radio plus transverter (→ 432). The key is the WSJT-X --rig-name / UDP id, and the N1MM station name when RadioInfo is the IF. Saved on this PC (if_seats.json). Each other host has its own file; the seat agent page can mark that PC’s radios the same way. Nothing to set for a normal HF or VHF dial.

Other networked PCs

N1MM is one per band; WSJT-X may be on other PCs/sites (e.g. TV-station 50, dual 144 FT8/MSK). 222/432 are usually one PC (SSB and/or FT8). WS Hub server is typically one Linux box. Operators open this console in a browser — they do not need multicast to their laptop.
