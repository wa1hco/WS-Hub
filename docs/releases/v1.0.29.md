# WS Hub 1.0.29

What changed since 1.0.28. Cluster spots are ranked by what looks workable from your grid, using PSK Reporter and your own recent decodes. A person still starts every transmit.

## Updates

**Spot ranking from PSK Reporter.** The site server asks PSK Reporter, at most every five minutes, for reports with one end in your Setup Station grid, or a live WSJT-X grid if that field is blank. A grid from a WSJT-X settings file is never used. Spots on a band with recent reports toward the DX's direction sort first. The others stay listed and are dimmed. Each row has a gray CLU tag. Hovering a row explains why, for example "Open: 12 FN41 reports toward 45° on 20m in last 30 min". A Cluster checkbox next to the mode filters can hide the list. Setup has a Station grid field, a "Use PSK Reporter to rank spots" checkbox (on by default), and a status line such as "PSK Reporter: 340 reports from FN41, updated 2 min ago". If the service is down, spots are not dimmed.

## Installing from this page

**Linux.** Download `wims-1.0.29-linux-x86_64.tar.gz` and unpack it anywhere. Open the folder, open **scripts**, and double-click **Install WS Hub**. If the file manager asks once, choose **Allow Launching**, **Execute**, or **Run**. Then delete the download and double-click **WS Hub**.

**Windows.** Download `wims-1.0.29-windows-x86_64.zip` and extract it to `C:\WIMS`. Open `C:\WIMS\scripts\windows` and double-click **Install-Wims.cmd**. Then double-click **WS Hub**.
