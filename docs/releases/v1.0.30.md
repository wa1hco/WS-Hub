# WS Hub 1.0.30

What changed since 1.0.29. Remaining user-facing WIMS names now say WS Hub. A person still starts every transmit.

## Updates

**WS Hub branding.** Window titles, the About box and other dialogs, console pages, the launcher heading, tooltips, status and error messages, the installer, desktop and Start menu wording, and the documentation now say **WS Hub**. The desktop icon already showed WS over HUB. Help links that still pointed at the old `wa1hco/WIMS` repository now point at [wa1hco/WS-Hub](https://github.com/wa1hco/WS-Hub).

On Windows, putting the icon on the desktop is **Add WS Hub to Desktop.bat**. The older **Add WIMS to Desktop.bat** name still runs that file. Installing or updating also writes an **Update WS Hub** shortcut and removes leftover **WIMS** and **Update WIMS** desktop and Start menu icons.

The package, folders, and file names still use `wims` (for example `src/wims`, `C:\WIMS`, and `wims-1.0.30-…`). That is expected, so existing settings and installs keep working.

## Installing from this page

**Linux.** Download `wims-1.0.30-linux-x86_64.tar.gz` and unpack it anywhere. Open the folder, open **scripts**, and double-click **Install WS Hub**. If the file manager asks once, choose **Allow Launching**, **Execute**, or **Run**. Then delete the download and double-click **WS Hub**.

**Windows.** Download `wims-1.0.30-windows-x86_64.zip` and extract it to `C:\WIMS`. Open `C:\WIMS\scripts\windows` and double-click **Install-Wims.cmd**. Then double-click **WS Hub**.
