# WS Hub 1.0.38

What changed since 1.0.37. Spotted shows the real mode for DATA cluster spots, drops WSPR, and has a simpler PSKR Spotter column. A person still starts every transmit. Nothing in this release transmits or retunes a radio.

## Updates

**DATA cluster spots show their real mode.** A cluster spot with no mode in its comment, away from the usual FT8 frequency, used to be labeled **data**, and you had to tick **Other** to see it. Since 1.0.36, when PSK Reporter also heard that station, the row turned into a blue PSKR row marked FT8, yet it still only appeared with **Other** ticked. Now, when PSK Reporter has the same call on the same band, the spot shows that mode (for example FT8), even with PSKR rows hidden. The mode boxes on Operate now go by the mode you see in the row, so an FT8 row appears under **FT8**. A spot that PSK Reporter has not heard still says **data** and still sits under **Other**. Cluster comments that say **F/H**, **Fox**, **Hound**, or **SuperFox** are now read as FT8.

**WSPR is kept off Spotted.** WSPR and FST4W are beacons that cannot be worked, so they no longer appear on Spotted, whether they come from PSK Reporter or the cluster. WS Hub still uses those reports in the background to judge which bands are open.

**PSKR Spotter shows just the call.** The Spotter column on a PSKR row now shows only the receiving station's call, such as `PSKR KM3T`. The `+1` (how many other receivers heard the station) and the `-2` (part of a receiver's callsign, such as `KM3T-2`) are gone. Hover the row to see every receiver.

## Installing from this page

**Linux.** Download `wims-1.0.38-linux-x86_64.tar.gz` and unpack it anywhere. Open the folder, open **scripts**, and double-click **Install WS Hub**. If the file manager asks once, choose **Allow Launching**, **Execute**, or **Run**. Then delete the download and double-click **WS Hub**.

**Windows.** Download `wims-1.0.38-windows-x86_64.zip` and extract it to `C:\WIMS`. Open `C:\WIMS\scripts\windows` and double-click **Install-Wims.cmd**. Then double-click **WS Hub**.
