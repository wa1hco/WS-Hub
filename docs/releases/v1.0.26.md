# WS Hub 1.0.26

What changed since 1.0.25. When you connect to a DX cluster, the Station call is filled in for you. A person still starts every transmit.

## Updates

**Station call for the DX cluster.** The cluster logs in with the Station call from Setup. If that field is empty, WIMS fills it from a running WSJT-X, or from a logger if WSJT-X has no call. A call you already typed is left alone, and a blank Save does not wipe a known call. The call is never taken from a WSJT-X settings file. If no call is known, the status asks you to set it in Setup.

## Installing from this page

**Linux.** Download `wims-1.0.26-linux-x86_64.tar.gz` and unpack it anywhere. Open the folder, open **scripts**, and double-click **Install WS Hub**. If the file manager asks once, choose **Allow Launching**, **Execute**, or **Run**. Then delete the download and double-click **WS Hub**.

**Windows.** Download `wims-1.0.26-windows-x86_64.zip` and extract it to `C:\WIMS`. Open `C:\WIMS\scripts\windows` and double-click **Install-Wims.cmd**. Then double-click **WS Hub**.
