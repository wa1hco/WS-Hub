# WS Hub 1.0.25

What changed since 1.0.24. The launcher uses one site-server address for the reachability check, the status line, and Open site console. Open local status stays on this PC. A person still starts every transmit.

## Updates

**One address for the site server.** The check, the status line, and Open site console all use the same host. If the site server is on this PC, the window opens on this PC and the status line still shows the LAN address other computers should use. Open local status is this PC's seat page, not the site console, and it no longer reuses a site-console window. If the console cannot be reached, the browser is not opened, so the window does not hang.

**A heard announcement is not enough.** Another PC announcing a site server is only treated as up if the console answers. If it does not, this PC can be the site server. The status line is a short sentence, such as "Site server: this PC, running at 192.168.2.113:8787", and never a bare network such as 192.168.2.113/24.

**If the site console is not reachable from another PC.** The site server already listens on every network on that computer. When the status line says the server is running here but another PC cannot open it, allow the site console through the firewall on the PC that is running the server, or run the site server on a PC the others can reach.

**Launcher cleanup.** Install this update is hidden when this copy is already current. Hover an update row to read what changed. Check logs is in the site console, including Check logs on this computer for the logs on the seat PC.

## Installing from this page

**Linux.** Download `wims-1.0.25-linux-x86_64.tar.gz` and unpack it anywhere. Open the folder, open **scripts**, and double-click **Install WS Hub**. If the file manager asks once, choose **Allow Launching**, **Execute**, or **Run**. Then delete the download and double-click **WS Hub**.

**Windows.** Download `wims-1.0.25-windows-x86_64.zip` and extract it to `C:\WIMS`. Open `C:\WIMS\scripts\windows` and double-click **Install-Wims.cmd**. Then double-click **WS Hub**.
