# WS Hub 1.0.35

What changed since 1.0.34. A small update to the call roster menu. A person still starts every transmit.

## Updates

**Call roster show menu.** The menu now reads **All**, then **Needed**, then **Needed and CQ** and **Needed and CQ or 73**. Needed is still the starting choice, and the choice you made last time is kept.

**Newer WS Skim versions.** WS Skim now names each section by its dial in kHz, for example `SKIM-FLEX-40m-FT8-74`. WS Hub already handles those names, and the "Skimmer ids" setting `SKIM-*, WS-Skim*` still covers them. Nothing to change in Setup.

## Installing from this page

**Linux.** Download `wims-1.0.35-linux-x86_64.tar.gz` and unpack it anywhere. Open the folder, open **scripts**, and double-click **Install WS Hub**. If the file manager asks once, choose **Allow Launching**, **Execute**, or **Run**. Then delete the download and double-click **WS Hub**.

**Windows.** Download `wims-1.0.35-windows-x86_64.zip` and extract it to `C:\WIMS`. Open `C:\WIMS\scripts\windows` and double-click **Install-Wims.cmd**. Then double-click **WS Hub**.
