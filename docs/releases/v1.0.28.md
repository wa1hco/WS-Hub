# WS Hub 1.0.28

What changed since 1.0.27. Setup has a Cluster login field so two stations can share one DX cluster node. A person still starts every transmit.

## Updates

**Cluster login.** A new Cluster login field on Setup accepts a login such as WA1HCO-1 or WA1HCO-2. That value is used only as the telnet login. The Station call stays your station identity and is never changed by the suffix. Leave Cluster login blank to use the Station call. If a value is not a valid login, Setup shows an error and keeps the last saved settings. A typed value is not overwritten by auto-fill.

## Installing from this page

**Linux.** Download `wims-1.0.28-linux-x86_64.tar.gz` and unpack it anywhere. Open the folder, open **scripts**, and double-click **Install WS Hub**. If the file manager asks once, choose **Allow Launching**, **Execute**, or **Run**. Then delete the download and double-click **WS Hub**.

**Windows.** Download `wims-1.0.28-windows-x86_64.zip` and extract it to `C:\WIMS`. Open `C:\WIMS\scripts\windows` and double-click **Install-Wims.cmd**. Then double-click **WS Hub**.
