# WS Hub 1.0.31

What changed since 1.0.30. The launcher finds the station's site server on another PC instead of getting stuck on an old copy left on this PC. A person still starts every transmit.

## Fixes

**Site server on another PC is found first.** Before Start site server runs one on this PC, the launcher looks on the network. If another PC already has the site server and it answers, the launcher uses it, says which PC it is, and does not start a second one.

**Old copies left after an update.** A site server left running on this PC from an earlier version is no longer taken as the station's server, or offered for Restart, until the launcher has checked the network. If another PC has the site server, the launcher uses that one and leaves the old copy alone.

**Restart site server.** Restart now waits for the old copy to finish exiting before it starts the new one, so it no longer stops the server and then refuses to start another. If a restart still fails, the launcher looks on the network for a site server instead of staying on this PC with nothing running.

**The site server keeps announcing itself.** A site server that heard another server it could not reach (often because that PC's firewall blocks the site console) used to stop announcing itself without saying so. It now keeps announcing. If it cannot announce or listen, it says so in its log and on its status.

**Leftover record cleared.** The launcher removes the record of a site server process that is no longer running.

## Installing from this page

**Linux.** Download `wims-1.0.31-linux-x86_64.tar.gz` and unpack it anywhere. Open the folder, open **scripts**, and double-click **Install WS Hub**. If the file manager asks once, choose **Allow Launching**, **Execute**, or **Run**. Then delete the download and double-click **WS Hub**.

**Windows.** Download `wims-1.0.31-windows-x86_64.zip` and extract it to `C:\WIMS`. Open `C:\WIMS\scripts\windows` and double-click **Install-Wims.cmd**. Then double-click **WS Hub**.
