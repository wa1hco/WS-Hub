# WS Hub 1.0.33

What changed since 1.0.32. Stations that WS Skim decodes now show on the Spotted list as green SKIM spots. A person still starts every transmit.

## Updates

**WS Skim spots.** When WS Skim sends its decodes to the site server, every station it decodes shows on Operate, Spotted, with a green SKIM tag at its exact frequency. Heard-here spots sort first and are never dimmed. A DX cluster spot of a station that WS Skim also hears turns into a SKIM line. Cluster-only lines keep the gray CLU tag. A Skim checkbox next to Cluster hides or shows them. Skim spots drop off after 15 minutes, like cluster spots, and they show even with the cluster turned off. WS Skim decodes also count as proof that a band is open when ranking cluster spots. A click on a SKIM spot only selects the station. It does not transmit, retune, or turn an antenna.

**A skimmer is never a WSJT-X program.** WS Skim does not appear on Overview or the call roster, and nothing in WS Hub can reply to it or set it up. Its decodes are not passed to GridTracker.

**Setup, Skim receivers.** A new section says where to point WS Skim and which skim receivers the site server hears. In WS Skim, open Reporting, check WSJT-X UDP Enable, use Port 2237, and use Host 224.0.0.73 so any PC on your network reaches the site server. 127.0.0.1 works only when WS Skim runs on the same PC as the site server. "Skimmer ids" starts as `SKIM-*, WS-Skim*`, which covers WS Skim.

## Installing from this page

**Linux.** Download `wims-1.0.33-linux-x86_64.tar.gz` and unpack it anywhere. Open the folder, open **scripts**, and double-click **Install WS Hub**. If the file manager asks once, choose **Allow Launching**, **Execute**, or **Run**. Then delete the download and double-click **WS Hub**.

**Windows.** Download `wims-1.0.33-windows-x86_64.zip` and extract it to `C:\WIMS`. Open `C:\WIMS\scripts\windows` and double-click **Install-Wims.cmd**. Then double-click **WS Hub**.
