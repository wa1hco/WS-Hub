# WS Hub 1.0.27

What changed since 1.0.26. The DX cluster retries sooner after a drop, and the status line says what actually happened. A person still starts every transmit.

## Updates

**Cluster retry and status.** If the node hangs up, WS Hub closes that connection right away and tries again in a few seconds, then up to one minute. A failed connect says it can't reach the host, for example "Cluster: can't reach k1ttt.net:7373, retrying in 30 s". If the node accepted the connection and then closed it, the line says the node closed the connection. "Logged in" appears only while the login is actually up, such as "Cluster: logged in as WA1HCO, 12 spots".

## Installing from this page

**Linux.** Download `wims-1.0.27-linux-x86_64.tar.gz` and unpack it anywhere. Open the folder, open **scripts**, and double-click **Install WS Hub**. If the file manager asks once, choose **Allow Launching**, **Execute**, or **Run**. Then delete the download and double-click **WS Hub**.

**Windows.** Download `wims-1.0.27-windows-x86_64.zip` and extract it to `C:\WIMS`. Open `C:\WIMS\scripts\windows` and double-click **Install-Wims.cmd**. Then double-click **WS Hub**.
